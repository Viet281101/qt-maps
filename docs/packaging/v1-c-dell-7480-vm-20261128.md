# V1-C — exact internal candidate on Dell Latitude 7480, 2026-11-28

**Result:** offline functional GUI smoke passed on a clean Ubuntu 26.04.1
Desktop VM using the exact local real-data archive. This closes the V1-C
clean-target functional check; it is not a GPU benchmark, a public binary
distribution approval or a v1.0 release.

## Target and provenance

- Owner's `viet-anh-Latitude-7480`: Ubuntu 24.04 host, 7.6 GiB RAM. The
  existing Unit 14A qcow2 was not changed. A separate 60 GiB qcow2 was made
  with `qemu-img convert -l provisioned` from its pre-data snapshot.
- Guest: Ubuntu 26.04.1 LTS, kernel `7.0.0-30-generic`, glibc 2.43,
  `libqt5core5t64` 5.15.18+dfsg-1ubuntu1. QEMU/KVM used 2 vCPU, 6 GiB RAM,
  `-nic none`, `-display gtk,gl=off` and no GPU passthrough. Guest preflight
  recorded only loopback and no IPv4 or IPv6 default route.
- The 543,496,479-byte candidate tied to source commit `3016987` moved by
  direct SSH on the owner's local network to the Dell only. SHA-256
  `26cb328c7b670c888e03ab71310acf82f4843d5591e335152db47e612fec3f45`
  passed on the Dell host and again in the guest through a read-only 9p mount.
  The host extracted the checked archive to that mount. No public CI or shared
  service received the archive.
- Guest checked all 1,092 staged file hashes, then used the archive's
  `install.sh install` into a new guest destination. It activated bundle
  `vietnam-v1-candidate` and graph `vietnam-national-valhalla391`; startup,
  9,094 real FTS5 rows and `MATCH`, rollback mechanics and invalid-input
  rejection passed. The installed graph was selected on launch.
