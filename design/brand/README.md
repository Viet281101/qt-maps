# QtMaps Brand Reference

The runtime source of truth is `qml/theme/Theme.qml`.

| Role | Current token |
| --- | --- |
| Surface | `surface`, `surfaceElevated`, `surfaceInput` |
| Text | `textPrimary`, `textSecondary` |
| Action | `accent`, `success`, `warning`, `error` |
| Route | `route`, `routeOutline`, `routeTravelled` |
| Typography | `fontFamily`, `fontSizeCaption`, `fontSizeBody`, `fontSizeTitle`, `fontSizeDisplay` |

Use the available system sans-serif and Theme pixel sizes. No font is bundled
or downloaded; this reference must not become a parallel token definition.
